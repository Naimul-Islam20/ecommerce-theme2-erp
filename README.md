# Deshojo Bazar

Premium storefront for Deshojo Bazar, converted to **Next.js (App Router)** and **Tailwind CSS**.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

- `/` homepage
- `/shop` catalog, category filter, search and sort
- `/product/[id]` product detail
- `/checkout` demo checkout
- `/impact` Tahirpur Haor initiative
- `/reviva` intangible heritage
- `/farming/haor|drought|coast|hill|flood`

Cart, search and the mobile menu persist in the browser via `localStorage`. Checkout is still a frontend prototype until a real commerce API is connected.
